Enforcing Scientific Guardrails on Autonomous LLMs

When AI coding assistants are left ungoverned, they silently modify datasets, fish for p-values, and hallucinate uncalibrated trendlines. OmniResearch establishes hard deterministic boundaries.

01 / TAMPER DETECTION

Raw Data Tamper-Evidence

01_data/raw/ is monitored under continuous cryptographic integrity checks. The agent is restricted from modifying raw files in place, with every execution validated against SHA-256 baselines.

02 / PREREGISTRATION

Hypothesis Ledger

Before executing regressions or neural sweeps, null (H₀) and alternative (H₁) hypotheses, significance α thresholds, and power plans are committed to a local preregistration ledger in 00_meta/.

03 / MANDATORY UNCERTAINTY

Error Bounds & Sensitivity

Point estimates without standard errors or 95% confidence intervals are rejected. Every reported metric must undergo ablation and sensitivity testing.

04 / CRYPTOGRAPHIC LINEAGE

Manifest Receipts

Every plot and table is cryptographically bonded to the raw inputs, transformation script, seed, and OS specs in 05_artifacts/provenance/manifest.json.

PILLAR 01 // HUMAN-IN-THE-LOOP gate_check.py

Approval Gates & Digital Signatures

Replaces unmonitored exploratory runs with structured human oversight. Requires explicit researcher digital approval before unlocking data execution pipelines and statistical inferences in 00_meta/.

$ python gate_check.py lock --gate hypothesis-lock
PILLAR 02 // PUBLICATION READY generate_appendix.py

Auto-Appendix for Journals

Streamlines technical documentation for peer-review. Automatically compiles standardized LaTeX (booktabs) and Markdown methodology appendices directly from cryptographic lineage manifests.

$ python generate_appendix.py --project . --format all
PILLAR 03 // PRE-EXECUTION AUDIT scan_leakage.py

Real-time Data Leakage Scanner

Static code analysis powered by Python Abstract Syntax Trees (AST). Automatically intercepts pre-split transformations (e.g. StandardScaler.fit() prior to split) and temporal shuffle leaks before execution.

$ python scan_leakage.py 03_src/python --strict
PILLAR 04 // BIG DATA SCALE record_provenance.py

Streaming Buffers & Merkle Trees

Engineered for high-throughput genomic, physical, and observational datasets. Uses 8MB streaming buffers and 64MB chunked Merkle Tree roots for scalable, memory-efficient data integrity checks.

$ python record_provenance.py --verify --manifest ...

Modality Hygiene

Six Specialized Scientific Data Handlers

Specialized ingestion protocols tailored to domain data structures. Coordinates, sampling frequencies, and missingness are audited before modeling.

Tabular & Survey Data

.csv .parquet .dta

Handles survey weights, multi-stage stratification (PSU/strata), and multivariate imputation (MICE).

Guardrail: Global imputation prior to train/test split is strictly rejected.

Spatial & Geospatial

.geojson .tif .shp

Coordinate Reference System (CRS) hygiene and spatial autocorrelation (Moran's I).

Guardrail: Explicit EPSG projection transformation required before distance calculation.

Biological Sequences

.fasta .pdb .sdf

RNA-Seq normalization (DESeq2), 3D PDB structure analysis, and SMILES cheminformatics.

Guardrail: Library size and dispersion checked prior to differential expression.

Signals & Sensor Streams

.edf .wav .h5

Biomedical and physical time series (EEG/ECG). Nyquist theorem compliance and bandpass filters.

Guardrail: Phase distortion prevented via forward-backward digital filtering (filtfilt).

Text Corpora & Humanities

.txt .xml .tei

Quantitative stylometry (Burrows' Delta), topic modeling (BERTopic), and lemmatized collocations.

Guardrail: Stopword dictionaries and tokenizer choices fully documented in 02_methodology/.

Graphs & Complex Networks

.gexf .graphml

Topological properties: degree distributions, small-worldness, and community modularity.

Guardrail: Multi-edges and self-loops explicitly handled before matrix decomposition.
